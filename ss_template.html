NextSeq 2000 SampleSheet Generator v2 / BCLConvert

Enter run details and samples. Names, index uniqueness (Hamming), and index length are validated live. Export an Illumina v2 sample sheet.

1 · Run setup

Index cycles are inferred from the selected indexes; leave blank for auto, or type a value to override (shorter indexes are N-padded in OverrideCycles).

2 · Projects — one run can hold several projects, each with its own index kit

3 · Samples

4 · Validation — across the whole run

    Hamming check compares each pair's combined index (i7+i5). A distance < 3 (fewer than 3 differing bases) risks demultiplexing collisions and is flagged.

    5 · Sample sheet output

    Copy for BaseSpace → paste straight into the Run Planning sample table (tab-separated: Sample_ID, Index, Index2 — plus Project when the run has several). “Sample sheet” = BCL Convert v2 file to upload instead · Index & Index2 both forward (BaseSpace reverse-complements i5 for the NextSeq 2000). Multi-project runs get a Sample_Project column, so FASTQs land in per-project folders. “Records” = full archive table.
